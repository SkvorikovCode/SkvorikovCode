## 👋 Обо мне

Full-stack разработчик. Делаю **инструменты для AI-агентов, которые пишут код**, и выкладываю их в open source.

Сейчас большая часть моего кода пишется вместе с агентами: я проектирую систему, запускаю несколько агентов параллельно, ревьюю диффы и слежу, чтобы архитектура не разваливалась. Из этого процесса и растут мои проекты — десктоп-приложения для агентов, LLM-пайплайны, Telegram-боты и автоматизация вокруг генеративных моделей.

## 🐙 Главный проект

**[Octopus AI](https://github.com/SkvorikovCode/Octopus-AI)** · [сайт](https://skvorikovcode.github.io/Octopus-AI/) · [README на русском](https://github.com/SkvorikovCode/Octopus-AI/blob/main/README.ru.md)

Десктоп-приложение для AI-агентов, которые пишут код: запускайте одного агента или целый рой параллельно, каждого в своём git worktree. Вместо стены логов — понятные карточки разрешений и чистый дифф. Свои ключи — они хранятся в системной связке ключей, а код не покидает вашу машину.

`Tauri 2` · `Rust` · `React` · `TypeScript` · Apache-2.0 · PR приветствуются
